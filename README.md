# first-repo

我的第一个 GitHub 仓库。

## 本机环境
- Git 2.54.0 (Windows)
- SSH 连接方式：ed25519 密钥
- 提交邮箱使用 GitHub 隐私邮箱，避免暴露个人邮箱

## 常用命令速查
| 作用 | 命令 |
|------|------|
| 拉最新代码 | `git pull` |
| 提交改动 | `git add . && git commit -m "说明"` |
| 推送到 GitHub | `git push` |
| 查看状态 | `git status` |
